Редактирование цен

i
Что тут менять
  • Каждая строка — отдельный тариф или ставка, участвующая в формулах расчёта (утепление, надбавки за каркас, замена каркаса, поднятие стен и т.д.)
  • Меняете число → «Сохранить» → сумма в калькуляторе сразу пересчитается
  • Названия дропдаунов утепления (например «150мм +3700 р/м²») обновятся автоматически — текст подписи не зашит вручную
  • Удалить строку тут нельзя — список фиксированный, это именно тарифы, а не позиции для добавления/удаления (для этого — раздел «Материалы»)
  • «Сбросить настройки» вернёт все цифры к значениям по умолчанию — необратимо для несохранённого на GitHub состояния
  • Изменения видны только вам, пока не скачаете config.js и не замените им файл на GitHub

Измените цену и нажмите «Сохранить». Скачайте config.js и залейте на GitHub — цены обновятся для всех.

Редактирование сайта — Внутренняя отделка

i

Изменения видны только вам, пока не скачаете materials.json и не замените им файл на GitHub — тогда обновится для всех посетителей сайта.

Публикация

i
Как это работает
  • Пока вы просто редактируете материалы — изменения видны только в вашем браузере (черновик)
  • «Опубликовать» сохраняет materials.json прямо в репозиторий на GitHub — после этого изменения увидят все посетители сайта, на любом устройстве
  • Токен нужен один раз — введите и нажмите «Запомнить на этом устройстве», чтобы не вводить каждый раз (хранится только в этом браузере, никуда не отправляется, кроме самого GitHub)
  • Как получить токen: GitHub → Settings → Developer settings → Personal access tokens → Generate new token (classic) → отметьте право repo
  • «Проверить подключение» — безопасно проверяет логин/токен/репозиторий, ничего не публикует

Сотрудники

i
Как это работает
  • Открытого входа "как гость" больше нет — попасть на сайт можно только по логину и паролю конкретного сотрудника
  • Пароль хранится только в виде хэша (как и у администратора) — сам пароль нигде не сохраняется, скопировать его обратно нельзя, только задать новый
  • Удалили сотрудника — он сразу теряет доступ, даже если раньше уже заходил на этом устройстве (это не локальный кэш браузера, список сотрудников общий для всех, из репозитория)
  • Изменения видны только вам, пока не нажмёте "Опубликовать на GitHub" (или не скачаете и не зальёте staff.json вручную)
  • Логин и пароль администратора тут не меняются — это отдельная, более высокая роль
